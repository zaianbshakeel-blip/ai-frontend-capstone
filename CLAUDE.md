# Front-end AI Capstone

## Project
This repository is for my Front-end AI Engineering capstone project.

## Planned Stack
- HTML5
- CSS3
- JavaScript
- React
- Vite

## Development Conventions
- Write clean, readable, and maintainable code.
- Use semantic HTML.
- Keep components reusable and organized.
- Use responsive design for desktop and mobile screens.
- Follow consistent naming conventions.
- Avoid unnecessary dependencies.
- Keep accessibility in mind.
- Test changes before considering a task complete.

## AI Assistant Guidelines
- Explain important changes briefly.
- Prefer simple and maintainable solutions.
- Do not modify unrelated files.
- Follow the existing project structure and conventions.

Project Rules
File references: HTML must reference style.css exactly for styling and script.js at the end of the body for JavaScript behavior.
Validation rules: Preserve the required validation patterns. Username must use /^[A-Za-z0-9_-]{3,20}$/ and email must use /^[^\s@]+@[^\s@]+\.[^\s@]+$/. Passwords must never be logged or stored in client-side persistence.
Accessibility: Every form control must have a visible associated label. Validation errors must be associated with their controls and communicated to users through appropriate ARIA attributes or live regions.
Form testing: Before committing form changes, test empty submission, invalid username, invalid email, weak password, missing theme, valid submission, and Reset behavior.
Keep the project simple: This is a small static frontend project, so prefer vanilla HTML, CSS, and JavaScript and avoid unnecessary dependencies or frameworks.
